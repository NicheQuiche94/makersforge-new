# Talent Directory profile template

Every public profile in `src/data/roster.ts` follows this shape, so the
directory reads consistently. New profiles should match the existing ones.

| Section | What goes in it | Bar |
|---|---|---|
| Role | Their level and specialism, e.g. "Game Designer, Economy & UI/UX" | 2–6 words |
| Background | One card line: years, specialism, most recent kind of studio | 1 sentence |
| Location | City and country, plus "· Remote" if relevant. Never just "eu" or "uk" | real place |
| Rates | Day rate if open to contract; salary if open to permanent; in their currency | both if open to both |
| Summary | What makes them different, in 2–3 sentences with one proof point | 300–500 chars |
| Skills | Tools and disciplines, most important first | 10–12 |
| Experience | Most recent first; what they owned and what changed because of it | 5–7 bullets |
| Motivations | Why they're looking and what they want next, in their terms | 2–4 sentences |
| Recruiter notes | Andre's own read: the standout, the fit, any honest caveat | 2–3 bullets |

## Rules
- **Anonymous.** No candidate name, no employer names. Describe employers
  ("a top-tier casual games studio", "a large European mobile studio").
  Public game titles can stay only if they don't identify the person.
- **No client-specific lines.** Nothing like "a big fan of <client>" or "applied
  for <role> at <client>".
- **Facts only from Andre's notes, spec or CV.** If something's missing, ask.
- **Consent, then Andre's sign-off on the copy, before it's committed.**
